This project is a Lung Cancer Prediction system built using Machine Learning in Python.
The model predicts the likelihood of lung cancer based on health-related factors such as smoking, anxiety, wheezing, coughing, chest pain, fatigue, and other symptoms.
The project includes data preprocessing, feature selection, model training, prediction, and model saving using joblib.

Features:
1.Data preprocessing and cleaning
2.Label encoding for categorical values
3.Feature selection using correlation
4.Lung cancer prediction using Machine Learning
5.Model training and evaluation
6.Model saving with joblib (.pkl file)

Technologies Used:
Python,Pandas,Scikit-learn,Joblib
